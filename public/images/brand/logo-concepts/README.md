# SailingLoc — pistes de logo

Ces fichiers PNG sont des planches de concept générées pour comparer quatre directions visuelles :

1. `01-minimal-sail-wave.png` — voile et vague formant un S fluide.
2. `02-geometric-sl-monogram.png` — monogramme géométrique SL pensé pour le digital.
3. `03-premium-editorial-wordmark.png` — mot-symbole éditorial et premium.
4. `04-friendly-peer-to-peer.png` — deux voiles illustrant la mise en relation.

Ce sont des supports d'exploration, pas encore des fichiers de production. La piste retenue devra être redessinée en SVG, déclinée sur fond clair et sombre, puis testée aux petites tailles.
